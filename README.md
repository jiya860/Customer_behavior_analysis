# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from loading and cleaning data in Python to performing SQL analysis, building an interactive Power BI dashboard, and presenting insights through a report and presentation.

The goal is to transform raw data into meaningful insights that support data-driven decision-making.

## Dataset

The dataset contains customer-related information used to analyze customer behavior, purchasing patterns, and business performance.

**Dataset includes:**

* Customer details
* Purchase information
* Transaction data
* Product and sales attributes

The dataset was loaded into Python for exploration and preprocessing before being analyzed using MySQL and Power BI.

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python using Pandas.
* Examined the dataset structure, columns, and data types.
* Checked the number of rows and columns.

### 2. Exploratory Data Analysis (EDA)

Performed EDA to understand the dataset and identify important patterns.

**Activities included:**

* Summary statistics
* Distribution analysis
* Missing-value checks
* Duplicate-value checks
* Relationship analysis between variables
* Visualization of important trends

### 3. Data Cleaning

Prepared the dataset for further analysis by:

* Handling missing values.
* Removing duplicate records.
* Correcting data types.
* Standardizing column names and values.
* Checking for inconsistent or invalid data.

### 4. SQL Analysis Using MySQL

Loaded the cleaned dataset into MySQL and performed SQL queries to answer business questions.

**Analysis included:**

* Total sales and revenue analysis.
* Customer segmentation.
* Purchase behavior analysis.
* Repeat customer analysis.
* Subscription and customer retention analysis.
* Gender-wise and category-wise comparisons.

SQL queries were used to extract useful insights from the database and support business decision-making.

### 5. Power BI Dashboard

Built an interactive Power BI dashboard to visualize key business metrics and customer insights.

**Dashboard features:**

* Key performance indicators (KPIs).
* Sales and revenue trends.
* Customer segmentation.
* Purchase behavior analysis.
* Interactive filters and slicers.
* Charts and visual summaries.

The dashboard helps users explore the data and identify important business patterns.

### 6. Report Creation

Created a detailed project report covering:

* Project objectives.
* Dataset description.
* Data preparation process.
* EDA findings.
* SQL analysis.
* Dashboard insights.
* Key conclusions.

### 7. Presentation Using Gamma

Created a professional PowerPoint presentation using Gamma to communicate the project workflow, analysis, dashboard, and key findings.

The presentation summarizes the problem, methodology, insights, and business recommendations.

## How to Run

### Prerequisites

Install the following tools:

* Python 3.x
* Jupyter Notebook
* MySQL
* Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/data-analytics-project.git
cd data-analytics-project
```

### Step 2: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 3: Run the Python Notebook

```bash
jupyter notebook
```

Open the notebook located in the `notebooks` folder and run the cells to load, clean, and analyze the dataset.

### Step 4: Run SQL Queries

1. Open MySQL Workbench.
2. Create a database.
3. Import the cleaned dataset.
4. Open the SQL file from the `sql` folder.
5. Execute the queries to reproduce the analysis.

### Step 5: Open the Power BI Dashboard

Open the `.pbix` file in Power BI Desktop.

If required, update the data source connection to your MySQL database and refresh the dashboard.
